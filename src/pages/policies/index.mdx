# Policies and support

## The evidence window

Every assignment closes at the stated deadline plus a 15-minute grace period —
after that, the case is closed and a late submission scores zero. If
something is going to stop you filing on time, say so *before* the deadline:
a short extension is granted routinely on request, and a longer one is
available through the usual extenuating-circumstances process. Asking after
the window closes is asking for a re-opened case, which is a much higher bar
than asking for more time in the first place.

## Chain of custody for your own work

This course spends twelve weeks teaching you to demand a traceable record
from everyone else's claims, so it holds your own work to the same standard.
Declare any tool that materially shaped a submission — including a
generative AI tool used for drafting, summarising or code — in a short note
at the end of the file. Undeclared assistance is treated the same way this
course treats an unlabelled synthetic image: not as a technical violation
first, but as a broken record that a reader can no longer trust without
independently re-verifying everything in it.

## A note on real cases

Several weeks use real, publicly reported incidents as case studies. Casework
built on a real person's content — a workplace document, a social media
post, a public figure's likeness — is for practising method, not for
publishing an accusation. Keep case write-ups inside the course; a genuine
concern about real, ongoing harm goes to a convenor, not onto a public
platform.

## Getting help

Questions about a specific week go to that week's tutor, in a session or by
email. Anything about the course as a whole — pacing, extensions, a concern
about how a case discussion went — goes to a convenor. Nobody in this course
expects you to already know the answer; they expect you to be able to say
what you checked.
